# Life-Like Organizer Test Cases

这些样本用于手测 MindFlow 的本地语义拆分。每条都尽量保留生活化、口语化输入，而不是规整清单。

## 1. 家人提醒 + 账单 + 家务

输入：

```text
我妈让我周五前把体检报告发给她，然后信用卡账单也没看，周末还想把厨房收拾一下。
```

期望拆分：

- 发送体检报告
- 查看信用卡账单
- 收拾厨房

## 2. 工作修改 + 回消息 + 取件

输入：

```text
刚才老板说那个方案明天下午前要再改一版，我还没回小陈消息，快递也没去拿。
```

期望拆分：

- 修改方案
- 回复小陈消息
- 取快递

## 3. 情绪上下文 + 证件 + 缴费 + 桌面整理

输入：

```text
我现在脑子有点乱，护照快过期了，水电费好像也没交，电脑桌面乱七八糟。
```

期望拆分：

- 更新护照
- 缴水电费
- 整理电脑桌面

## 4. 面试准备

输入：

```text
下周面试，但我简历还没改，作品集没整理，自我介绍也没练。
```

期望拆分：

- 面试准备

## 5. 低能量家务

输入：

```text
今天不太想动，但冰箱里的菜要处理一下，垃圾也该扔了，衣服还没晾。
```

期望拆分：

- 处理冰箱食材
- 扔垃圾
- 晾衣服

## 6. 本地产品自测

输入：

```text
我想先把 MindFlow 本地登录再测一遍，然后看一下整理速度，最后把改动提交。
```

期望拆分：

- 自测 MindFlow 本地登录
- 检查整理速度
- 提交改动

## 7. 来客准备

输入：

```text
明天朋友要来，客厅得收一下，杯子也要洗，顺便买点水果。
```

期望拆分：

- 收拾客厅
- 洗杯子
- 买水果

## 8. 焦虑上下文 + 行政事项 + 论文

输入：

```text
我有点焦虑，银行卡那个验证码没处理，医院预约也还没确认，论文摘要还差一版。
```

期望拆分：

- 处理银行卡验证码
- 确认医院预约
- 修改论文摘要

## 9. 申请材料

输入：

```text
周五之前要把申请材料发出去，推荐信还没提醒老师，作品集链接也要检查。
```

期望拆分：

- 发送申请材料
- 提醒老师推荐信
- 检查作品集链接

## 10. 回家路上顺手事项

输入：

```text
晚上回家前记得取快递，顺路买洗衣液，然后把物业群里的通知看一下。
```

期望拆分：

- 取快递
- 买洗衣液
- 查看物业通知
