# 需求文档

## 1. 应用概述

### 1.1 应用名称
小虾待办（Xiaoxia Todo）

### 1.2 应用描述
一款专为 ADHD 用户设计的智能待办微信小程序,采用菜单栏风格设计,通过 AI 智能分类、停车场机制和番茄钟专注模式,帮助用户高效管理任务、减少分心。

## 2. 用户与使用场景

### 2.1 目标用户
需要任务管理、容易分心的知识工作者

### 2.2 核心使用场景
- 用户通过文字输入一次性输入多条任务,AI 自动拆分、识别类型和优先级
- 用户在工作中突然产生想法,暂存至停车场避免打断当前任务
- 用户使用番茄钟进行专注工作,完成后休息
- 用户查看每日专注时长统计和效率趋势
- 用户编辑、搜索和管理任务

## 4. 业务规则与逻辑

### 4.1 AI 任务拆分与分类规则

#### 4.1.1 多任务拆分规则
- 用户一次性输入多条想法时,AI 自动识别并拆分为独立任务
- 拆分依据包括:标点符号分隔、语义断句、任务关键词识别
- 每条拆分后的任务独立分析优先级和类型

#### 4.1.2 优先级识别规则

| 用户输入示例 | 识别类型 | 优先级 | 分配位置 |
|------------|---------|-------|--------|
| 记得明天交简历 | 待办 | 高 | 今日待办 |
| 下午 3 点面试 | 日程 | 高 | 今日待办 |
| 紧急！马上处理 | 待办 | 高 | 今日待办 |
| 十万火急、火急、超级重要、非常紧急、赶紧、立马、刻不容缓、ASAP、优先处理 | 待办 | 高 | 今日待办 |
| 有空看看这个 | 停车场 | 中 | 停车场 |
| 想学习新技能 | 停车场 | 低 | 停车场 |
| 有空再说、不急、随时、有时间再、慢慢来、以后再、没那么重要、无所谓 | 停车场 | 低 | 停车场 |

#### 4.1.3 自动分配规则
- 高优先级任务:自动添加至今日待办列表
- 中优先级任务:自动添加至停车场列表
- 低优先级任务:自动添加至停车场列表

#### 4.1.4 大事件识别与拆解规则
- AI 判断输入为大事件时（如项目、活动、重要准备工作等）,自动拆解为 3 个子步骤
- 子步骤存储至任务数据的 subtasks 字段（jsonb 格式）
- 子步骤数据结构：[{content: string, completed: boolean}]
- 任务标记为大事件（is_big_event: true）

### 4.2 停车场智能提醒规则

#### 4.2.1 提醒提前天数计算规则
- AI 根据任务优先级和描述中事件大小自动判断提前提醒天数:
  - 大事件/高优先级：提前 3-7 天提醒
  - 中等任务/中优先级：提前 1-3 天提醒
  - 小事/低优先级：提前当天或1天提醒
- 提前天数存储至任务数据的 remind_days_before 字段

#### 4.2.2 提醒卡片展示规则
- 停车场中的任务,在临近截止时间前,根据 remind_days_before 字段判断是否需要提醒
- 需要提醒的任务在「今日」Tab 的停车场提醒卡片区域显示
- 提醒卡片按截止时间从近到远排序

### 4.3 AI 分析接口

**请求示例:**
```
POST /api/ai/analyze
{
  \"input\": \"明天下午 3 点开会记得准备材料,有空看看新项目方案,学习一下 Python\"
}
```

**响应示例:**
```
{
  \"tasks\": [
    {
      \"type\": \"schedule\",
      \"content\": \"开会,准备材料\",
      \"priority\": \"high\",
      \"dueTime\": \"明天下午 3 点\",
      \"aiNote\": \"已识别为日程\",
      \"assignTo\": \"today\",
      \"isBigEvent\": false,
      \"subtasks\": [],
      \"remindDaysBefore\": 0
    },
    {
      \"type\": \"todo\",
      \"content\": \"看新项目方案\",
      \"priority\": \"medium\",
      \"aiNote\": \"已识别为待办\",
      \"assignTo\": \"parking\",
      \"isBigEvent\": false,
      \"subtasks\": [],
      \"remindDaysBefore\": 2
    },
    {
      \"type\": \"todo\",
      \"content\": \"学习 Python\",
      \"priority\": \"low\",
      \"aiNote\": \"已识别为学习任务\",
      \"assignTo\": \"parking\",
      \"isBigEvent\": false,
      \"subtasks\": [],
      \"remindDaysBefore\": 1
    }
  ]
}
```

**大事件拆解示例:**
```
POST /api/ai/analyze
{
  \"input\": \"准备下个月的产品发布会\"
}
```

**响应示例:**
```
{
  \"tasks\": [
    {
      \"type\": \"todo\",
      \"content\": \"准备下个月的产品发布会\",
      \"priority\": \"high\",
      \"aiNote\": \"已识别为大事件\",
      \"assignTo\": \"parking\",
      \"isBigEvent\": true,
      \"subtasks\": [
        {\"content\": \"确定发布会场地和时间\", \"completed\": false},
        {\"content\": \"准备产品演示材料和PPT\", \"completed\": false},
        {\"content\": \"邀请嘉宾和媒体\", \"completed\": false}
      ],
      \"remindDaysBefore\": 7
    }
  ]
}
```

**子步骤重新生成接口:**
```
POST /api/ai/regenerate-subtasks
{
  \"taskId\": 123,
  \"taskContent\": \"准备下个月的产品发布会\"
}
```

**响应示例:**
```
{
  \"subtasks\": [
    {\"content\": \"确定发布会场地和时间\", \"completed\": false},
    {\"content\": \"准备产品演示材料和PPT\", \"completed\": false},
    {\"content\": \"邀请嘉宾和媒体\", \"completed\": false}
  ]
}
```

### 4.4 任务数据模型

```
interface Todo {
  id: number
  content: string
  priority: 'high' | 'medium' | 'low'
  completed: boolean
  type: 'todo'
  dueTime?: string
  aiNote?: string
  isSchedule: boolean
  tags: string[]
  assignTo: 'today' | 'parking'
  isBigEvent: boolean
  subtasks: {content: string, completed: boolean}[]
  remindDaysBefore: number
  createdAt: Date
  updatedAt: Date
}
```

### 4.5 番茄钟规则
- 专注模式:25 分钟倒计时
- 短休息:5 分钟倒计时
- 长休息:15 分钟倒计时
- 每完成 4 个专注番茄钟后,自动提示进入长休息
- 倒计时结束后播放提示音
- 每次完成专注番茄钟后,自动记录专注时长至统计数据

### 4.6 进度计算规则
- 进度百分比 = 已完成任务数 / 今日待办总数 × 100%
- 实时更新进度条显示

### 4.7 深色模式切换
- 点击标题栏右侧深色模式按钮,切换浅色/深色主题
- 主题设置持久化保存

### 4.8 任务搜索规则
- 支持按任务内容（content 字段）进行模糊搜索
- 支持按任务标签（tags 数组）进行精确搜索
- 输入关键词后,同时匹配任务内容和标签
- 搜索结果实时更新,采用 400ms 防抖机制
- 标签快捷筛选按钮展示用户已有的常用标签（按使用频率排序）

### 4.9 统计数据计算规则
- 专注时长统计:累计所有完成的专注番茄钟时长（每个 25 分钟）
- 番茄钟完成数量:累计所有完成的专注番茄钟次数
- 效率趋势图表:按日期聚合统计数据,生成专注时长柱状图和番茄钟完成数量折线图
- 历史已完成任务列表按日期分组,默认展开最近 3 天的任务

### 4.10 多设备数据同步
- 用户登录后,任务数据、统计数据、主题设置等自动同步至云端
- 用户在不同设备登录时,自动拉取云端数据
- 数据冲突时,以最新修改时间为准

### 4.11 注册与登录规则
- 用户首次使用需先注册账号
- 注册时需验证用户名唯一性
- 注册时需验证密码与确认密码一致
- 登录时验证用户名和密码匹配
- 登录成功后保持登录状态

## 5. 异常与边界情况

| 场景 | 处理方式 |
|-----|--------|
| 用户未登录 | 显示登录页,无法进入主界面 |
| 注册时用户名已存在 | 提示「用户名已存在,请更换」 |
| 注册时密码与确认密码不一致 | 提示「两次密码输入不一致」,拒绝提交 |
| 登录时用户名或密码错误 | 提示「用户名或密码错误」 |
| 闪念输入为空 | 发送按钮置灰,无法提交 |
| AI 分析接口失败 | 提示「分析失败,请重试」,任务默认添加至停车场 |
| AI 无法拆分任务 | 将整段输入作为单条任务处理,默认添加至停车场 |
| AI 无法拆解子步骤 | 提示「拆解失败,请重试」,任务标记为非大事件 |
| 子步骤重新生成失败 | 提示「重新生成失败,请重试」,保留原有子步骤 |
| 今日待办列表为空 | 显示「暂无待办,添加一个吧」 |
| 停车场列表为空 | 显示「暂无想法」 |
| 停车场提醒卡片为空 | 不显示提醒卡片区域 |
| 番茄钟倒计时结束 | 播放提示音,显示完成提示 |
| 搜索结果为空 | 显示「未找到相关任务」 |
| 统计数据为空 | 显示无数据引导卡片「还没有专注记录,去专注页开始第一个番茄钟吧」 |
| 历史已完成条目为空 | 显示「暂无已完成任务」 |
| 任务详情内容为空 | 保存按钮置灰,无法保存 |
| 数据同步失败 | 提示「同步失败,请检查网络」,数据保留在本地 |
| 搜索输入为空 | 显示全部任务列表 |
| 标签快捷筛选无常用标签 | 不显示标签快捷筛选按钮区域 |

## 6. 验收标准

1. 用户可通过注册页创建账号,注册时需输入用户名、密码、确认密码,两次密码必须一致
2. 用户可通过登录页登录账号
3. 用户可通过文字一次性输入多条任务,AI 自动拆分为独立任务
4. AI 自动识别每条任务的类型和优先级,支持更多紧急程度语义词汇
5. 高优先级任务自动添加至今日待办,中低优先级任务自动添加至停车场
6. AI 判断大事件时自动拆解为 3 个子步骤
7. 用户可在「今日」Tab 查看今日待办列表,显示任务内容、优先级、完成状态
8. 用户可在「今日」Tab 查看停车场提醒卡片,点击「立即专注」按钮将任务移入今日待办
9. 用户可在「停车场」Tab 查看所有停车场任务,支持按优先级和截止时间排序
10. 用户可在「专注」Tab 使用番茄钟进行专注、短休、长休倒计时
11. 用户可在「统计」Tab 查看历史已完成任务列表（按日期分组,支持展开/折叠）、专注时长统计（今日/本周/本月/累计）、番茄钟完成数量统计（今日/本周/本月/累计）、效率趋势图表（专注时长柱状图+番茄钟折线图,支持7/30/90天切换）
12. 用户首次进入统计页且无数据时,显示引导卡片,点击「去专注」按钮跳转至专注 Tab
13. 用户可点击今日待办页或停车场页标题栏的搜索按钮,跳转至任务搜索页
14. 用户可在搜索页输入关键词,同时匹配任务内容和标签,实时显示搜索结果（400ms 防抖）
15. 用户可在搜索页点击标签快捷筛选按钮,筛选包含该标签的任务
16. 用户可点击搜索结果中的任务,跳转至任务详情页
17. 用户可点击复选框切换任务完成状态,进度条实时更新
18. 用户可在任务详情页编辑任务内容、优先级、截止时间、标签、子步骤
19. 用户可点击「重新生成」按钮重新让 AI 拆解子步骤
20. 用户可切换深色模式,主题设置持久化保存
21. 用户数据在多设备间自动同步
22. 界面采用橙粉渐变主题,菜单栏风格设计
23. 所有交互具备流畅动画和悬停反馈
