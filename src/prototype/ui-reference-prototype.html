MindFlow UI reference study

从参考里提炼，而不是照抄

目标是做一个移动端首页方向：低压记录、只推荐一件事、给出一个很小的下一步， 同时保留“其他想法都还在”的安全感。

参考案例

Apple Journal

低压记录 / 避免空白页

借鉴它“从建议开始写”的感觉，但不做回忆相册式入口。

参考案例

Tiimo

神经多样性 / 可执行计划

借鉴脑内倾倒到清晰步骤的路径，但不做满屏日程。

参考案例

Structured

时间线 / 快速暂存

借鉴“一天里只看清下一段”的秩序感，但减少时间块压力。

How We Feel

情绪词汇 / 科学但亲近

借鉴柔和色彩和精确表达，让建议像陪用户辨认状态。

参考案例

Finch

轻量自我照顾 / 小完成感

借鉴小步完成的反馈，但不加入宠物、积分或游戏化层。

视觉风格提炼

温暖，但不甜腻；清楚，但不催促

用纸感底色承接杂乱输入，用沉静绿色表示“可执行”，用少量陶土色标记推荐。 整体避免红点、排行榜、复杂待办墙，也不把第一屏做成传统任务管理面板。
